# 关于我

我做前端六年，喜欢把复杂的东西收拾干净：删掉不必要的边框，统一那 8 个相近的灰色，
让一个按钮在 200ms 里刚好到位。

工作之外写一点开源、拍一点照片、把喜欢的字体收藏到文件夹里再也不用。
如果你在做一个需要“看起来就该长这样”的界面，我们大概聊得来。

## 技术栈

| 类别 | 内容 |
| --- | --- |
| 语言 | TypeScript · JavaScript · CSS |
| 框架 | React · Vue · Astro |
| 样式 | Tailwind · CSS Modules · PostCSS |
| 工程 | Vite · pnpm · GitHub Actions |
| 设计 | Figma · 设计 token · 无障碍 |

## 关注的方向

- **设计系统**：让 token 而不是页面成为约束，减少“差不多但不一样”的组件
- **性能**：首屏、交互延迟、包体，能测量才谈得上优化
- **可访问性**：键盘路径、对比度、语义结构，这些不是加分项而是及格线

## 这个站点

手写过一版纯 HTML/CSS 的版本，后来觉得内容会越来越多，改成了
**MkDocs + Material**：内容全部是 Markdown，搜索、导航、暗色模式都是现成的，
样式只保留了黑白灰这一套。
